# Privacy

DimSim runs locally in Chrome.

## Data stored

DimSim stores extension settings with `chrome.storage.sync`:

- enabled state
- working day start and end time
- shade colour
- pattern setting
- opacity

## Data access

DimSim runs on `https://calendar.google.com/calendar/*` so it can place the
shade overlay on Google Calendar views.

## Data sharing

DimSim does not send calendar data, settings, or browsing activity to any
external server.

The popup contains external links to GitHub and Buy Me a Coffee. Those sites are
only opened when clicked.
